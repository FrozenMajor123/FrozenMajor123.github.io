# Privacy Policy — Dell Home Server Telemetry

**Last updated: 29 October 2026**

## Purpose

Dell Home Server Telemetry is a personal-use application that monitors the operational health and availability of a privately operated home server.

## Information processed

The application is designed to process limited technical information, such as server availability, resource usage, temperature and monitoring timestamps.

It is not intended to upload personal documents, photographs, CCTV recordings, passwords or other household files.

## Google account and Drive access

The application uses Google OAuth to authorise access to Google Drive for storing private server-health summaries.

Telemetry files are stored in a Google Drive folder controlled by the application owner. They are not made publicly accessible through this website.

## Data sharing and retention

The application does not sell personal information or share telemetry with advertisers.

The owner controls the stored telemetry and may delete it from Google Drive. Google's own retention and deletion policies may also apply.

OAuth authorisation can be revoked through the owner's Google Account security settings.

## Website visitors

This website does not deliberately use advertising, analytics trackers or visitor-registration forms. It is hosted using GitHub Pages, and GitHub may process normal website-access information under its own privacy policy.

## Contact

Privacy enquiries can be directed to the developer using the support email address provided on the application's Google OAuth consent screen.
