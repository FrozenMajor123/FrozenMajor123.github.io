# Dell Home Server Telemetry

Dell Home Server Telemetry is a personal-use application for monitoring the health and availability of a privately operated home server.

The application is intended to use Google OAuth to allow its owner to upload limited server-health summaries to a private Google Drive folder. It is not a public monitoring service and does not offer user registration.

This website provides information about the application. It does not display telemetry, collect credentials or provide access to the home server.
